# API Coverage Analyzer Dashboard

A React + TypeScript + Vite dashboard for visualizing API test coverage reports generated by the API Tests Coverage Analyzer CLI.

## Features

- **Overview page** — Summary table with coverage %, threshold, and pass/fail status; bar chart for all coverage types
- **Detail pages** — Searchable tables and pie charts for endpoints, parameters, business rules, integration flows, security, error handling, and performance/resilience
- **Trends page** — Load multiple historical reports and visualize coverage over time with a line chart
- **Quality gate banners** — Red/yellow/green indicators when coverage fails or warns against thresholds
- **File upload** — Load any custom `coverage-summary.json` at runtime without restarting
- **Light/dark theme** — Toggle persisted in `localStorage`
- **Fully standalone** — No backend needed; loads JSON from the `public/reports/` folder

## Prerequisites

- Node.js 18+
- npm 9+

## Development

```bash
# From the dashboard/ directory
npm install
npm run dev
```

The dev server starts at http://localhost:5173.

## Build

```bash
npm run build
```

Output is placed in `dashboard/dist/`. Serve it with any static file server:

```bash
npm run preview       # Vite's built-in preview server
npx serve dist        # Or any other static server
```

## Tests

Tests use Jest + jsdom (not Vite's test runner).

```bash
npm test
```

Test files live in `src/__tests__/`.

## Integrating with the CLI

1. Run the CLI to generate a coverage report:
   ```bash
   cd ..
   node dist/index.js analyze --output reports/coverage-summary.json
   ```
2. Copy (or symlink) the generated report into the dashboard's public folder:
   ```bash
   cp ../reports/coverage-summary.json public/reports/coverage-summary.json
   ```
3. Build and serve the dashboard:
   ```bash
   npm run build
   npm run preview
   ```

Alternatively, use the **📂 Load Report** button in the dashboard UI to load any report file at runtime without a rebuild.

## Report Format

The dashboard expects JSON in this shape:

```json
{
  "generatedAt": "2024-01-15T12:00:00.000Z",
  "summary": [
    { "type": "endpoint", "totalItems": 10, "coveredItems": 8, "coveragePercent": 80 }
  ],
  "details": {
    "endpoint": {
      "items": [
        { "id": "GET /api/users", "covered": true, "tests": ["test_name"] }
      ]
    }
  }
}
```

Supported `type` values: `endpoint`, `parameter`, `business`, `integration`, `security`, `error`, `performance`, `resilience`.

## Thresholds

Default thresholds (from `coverage.config.json`) are:

| Type        | Threshold |
|-------------|-----------|
| endpoint    | 80%       |
| parameter   | 70%       |
| business    | 60%       |
| integration | 50%       |
| security    | 60%       |
| error       | 50%       |
| performance | 75%       |
| resilience  | 50%       |

Coverage within 10% below a threshold shows a yellow warning; below that shows red.
